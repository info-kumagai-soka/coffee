# コーヒー抽出記録＆在庫販売管理

コーヒー豆の抽出記録に加えて、商品の仕入・在庫・賞味期限・販売・配送・回収(POP/広告物の回収、売れ残り・返品商品の回収)までをまとめて管理できるWebアプリです。

## 使い方

### 抽出記録(豆・レシピ)

`index.html` をブラウザで直接開くだけで使えます。サーバのインストールは不要です。データはブラウザの localStorage に保存されます(サーバには送信されません)。

- **記録を追加**: 豆の名前、挽き具合、抽出方法(ペーパードリップ・ネルドリップ・エスプレッソ・フレンチプレス・サイフォン・水出し)、温度分類(ホット/アイス)、豆の量(g)、注湯ステップ(ステップ1〜5。各ステップの湯量(左)と抽出時間(右)をプルダウンで選択)、風味メモ、総合評価(★)を入力して保存します。「蒸らしを行う」チェックボックスで蒸らし工程の有無を切り替えられ、オンの場合は専用の「蒸らし時間(秒)」プルダウンで待ち時間を別途記録できます。合計抽出時間と総湯量は自動計算されます。
- **記録一覧**: 保存した記録を日付順に確認・編集・削除できます。豆名で絞り込みも可能です。
- **豆ごとの集計**: 豆ごとに記録件数・平均評価・よく使う抽出方法・ホット/アイスの内訳・よく使う挽き具合・平均豆量・平均総湯量・平均比率・平均蒸らし時間・平均合計抽出時間を確認できます。
- ページ下部の「JSONエクスポート/インポート」で他端末にデータを移せます。

### 仕入・在庫・賞味期限・販売・配送・回収(業務管理)

これらの機能は複数人・複数端末でのデータ共有を前提に、サーバー(Node.js)とデータベース(SQLite)で一元管理します。以下の手順でサーバーを起動してから、ブラウザで同じページを開いてください。

```bash
node server/server.js
# または
npm start
```

起動後、`http://localhost:3000` をブラウザで開くと、上部ナビゲーションに「商品・取引先」「仕入」「在庫・賞味期限」「販売」「配送」「回収」タブが追加されています。

- **商品・取引先**: 商品マスタ(名称・カテゴリ・単位・仕入/販売単価)と、取引先マスタ(仕入先・得意先・両方)を登録します。
- **仕入**: 仕入先・商品・数量・単価・ロット番号・賞味期限・保管場所を入力して登録すると、自動的に在庫ロットが作成されます。
- **在庫・賞味期限**: 在庫ロットを賞味期限が近い順に一覧表示します。期限まで7日以内は警告、期限切れ・廃棄済みは危険表示になります。手動での在庫調整・廃棄処理も行えます。
- **販売**: 商品・得意先・数量を入力して販売を登録すると、指定した在庫ロット(未指定の場合は賞味期限が近い順に自動選択)から在庫が引き当てられます。販売のキャンセルで在庫は自動的に戻し入れされます。
- **配送**: 販売に紐づく配送予定を登録し、状態(準備中/配送中/完了/延期/キャンセル)を管理します。
- **回収**: 店舗のPOP・広告物の回収や、売れ残り・返品商品(賞味期限接近品を含む)の回収予定・実績を管理します。

データは `data/coffee.db`(SQLite)に保存されます。このファイルはリポジトリには含まれません(`.gitignore`対象)。

## 技術構成

- 抽出記録タブ: 追加パッケージ不要の静的HTML/CSS/JavaScript(localStorage)
- 業務管理タブ: Node.js組み込みの `http` サーバーと `node:sqlite`(SQLite)のみで構成。npm install不要で `node server/server.js` だけで起動できます。
