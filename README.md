# コーヒー抽出記録ノート

コーヒー豆・挽き具合・蒸らし+注湯の多段階レシピ・風味を記録し、コーヒー豆ごとに集計できるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで使えます。サーバのインストールは不要です。

- **記録を追加**: 豆の名前、挽き具合、豆の量(g)、注湯ステップ(ステップ1:蒸らし、ステップ2〜5:注湯。各ステップの時間と湯量をプルダウンで選択)、風味メモ、総合評価(★)を入力して保存します。合計抽出時間と総湯量は各ステップの値から自動計算されます。
- **記録一覧**: 保存した記録を日付順に確認・編集・削除できます。豆名で絞り込みも可能です。各記録のステップごとの内訳も表示されます。
- **豆ごとの集計**: 豆ごとに記録件数・平均評価・よく使う挽き具合・平均豆量・平均総湯量・平均比率(豆:湯)・平均蒸らし時間・平均合計抽出時間を確認できます。

データはブラウザの localStorage に保存されます(サーバには送信されません)。他の端末に移す場合はページ下部の「JSONエクスポート/インポート」を利用してください。
