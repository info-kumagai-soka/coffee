# コーヒー抽出記録ノート

コーヒー豆・挽き具合・蒸らし時間・抽出時間・湯量・風味を記録し、コーヒー豆ごとに集計できるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで使えます。サーバのインストールは不要です。

- **記録を追加**: 豆の名前、挽き具合、蒸らし時間(秒)、抽出時間(秒)、湯量(ml)、風味メモ、総合評価(★)を入力して保存します。
- **記録一覧**: 保存した記録を日付順に確認・編集・削除できます。豆名で絞り込みも可能です。
- **豆ごとの集計**: 豆ごとに記録件数・平均評価・よく使う挽き具合・平均湯量・平均蒸らし時間・平均抽出時間を確認できます。

データはブラウザの localStorage に保存されます(サーバには送信されません)。他の端末に移す場合はページ下部の「JSONエクスポート/インポート」を利用してください。
